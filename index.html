    01

    외부 실행 환경 준비

    GitHub 저장소에 이 프로젝트의 수집 코드·설정·워크플로를 올립니다. 현재 프로젝트 저장소에 직접 접근할 수 없다면 소유자가 내려받아 본인 저장소로 옮겨야 합니다. 자동 활성화되지는 않습니다.

    02

    최초 1회 수동 실행

    저장소 Settings → Pages에서 GitHub Actions를 선택하고, Actions의 ‘RWA Radar — twice-daily research’에서 Run workflow를 누릅니다. 공개할 것은 조사결과뿐입니다. Pages 환경 승인·권한·요금 조건은 계정에 따라 다릅니다.

    03

    결과 URL 연결

    성공한 실행의 Summary에 표시된 monitor-feed.json 주소를 위에 입력합니다. 실제 수집 시각·성공/실패 건수를 확인해야 연결이 검증됩니다. URL만 저장했다고 예약이 켜지는 것은 아닙니다.

    04

    하루 두 번 실행 활성화

    Settings → Secrets and variables → Actions → Variables에 RADAR_ENABLE_SCHEDULE 값을 true로 등록합니다. 기본 브랜치의 워크플로에 오전 8:30·오후 5:00 한국시간이 설정되어 있습니다. GitHub 예약은 지연·누락될 수 있고 장기 비활성 저장소에서는 중지될 수 있습니다.

    현재 가동 여부는 실제 실행 기록으로 판단하세요. 이 편집 환경에서 외부 계정 설정·예약 활성화·운영 수집까지 대신 완료할 수는 없습니다. 정각 보장이 필요한 경우에는 별도 관리형 예약 서버가 필요합니다. 자세한 인계 문서: automation/SETUP.md
